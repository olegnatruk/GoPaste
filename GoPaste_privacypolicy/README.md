# GoPaste Privacy Policy

Standalone Vite site for the public GoPaste privacy-policy URL required by the Chrome Web Store.

## Run locally

```sh
npm install
npm run dev
```

## Deploy to Vercel

Import this folder as a Vercel project, or run `vercel` from this directory.

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`

Use the deployed URL in the Chrome Web Store **Privacy policy** field.
