## Listing copy

Suggested title: **GoPaste — GIF Library & CodeChum Assistant**

Suggested short description: **Save and share images and GIFs locally, and use an optional CodeChum coding assistant with Gemini.**

Suggested detailed description:

> GoPaste saves images and GIFs you choose into a local Chrome library. Organize them in categories, find them in the dashboard, copy or drag them into compatible websites, and export or restore ZIP backups.
>
> The extension also includes a clearly labeled CodeChum assistant. Members sign in through Supabase, choose a CodeChum problem tab, and may ask Gemini to prepare a candidate solution from the visible challenge, selected test cases, requirements, and their manually checked feedback. The candidate is entered into CodeChum's editor. The user chooses when to run CodeChum's Check code action. The assistant is optional and requires the member's own Gemini API key and affirmative consent before AI requests.
>
> Saved GoPaste media stays in the local Chrome profile and is not sent to Supabase or Gemini. CodeChum session information, API key, settings, and checkpoints are stored locally in extension storage. See the privacy policy for the distinct data flows.

The listing must not say the whole extension is device-only, has no accounts, or uses no remote AI. Screenshots should show the visible CodeChum entry and the consent state, in addition to GoPaste's library.

## Permission explanations

- `contextMenus`: add **Save to GoPaste** for user-selected images.
- `clipboardWrite`: copy saved images and GIFs after a user click.
- `downloads`: write user-requested ZIP exports and media downloads.
- `pageCapture`: recover selected media from a page snapshot when direct fetching fails.
- `scripting`: recover selected images and handle user-initiated CodeChum page reading and editor input.
- `unlimitedStorage`: hold the local binary media library beyond ordinary extension quotas.
- `storage`: keep CodeChum member session, settings, API key, consent, and resumable progress locally.
- `<all_urls>` host access: fetch selected images from arbitrary sites and attach GoPaste media on compatible websites. CodeChum actions are additionally restricted in code to CodeChum pages. This broad permission may trigger in-depth review.

`tabs` and `activeTab` should not be requested separately while existing host access and `scripting` provide the needed capabilities.

## Data disclosures to verify in the developer dashboard

- Supabase authentication handles member email, password submission, and access records. The extension keeps session tokens locally but not the password.
- Gemini receives the selected CodeChum challenge context, relevant candidate code, optional implementation notes, and manual-check feedback after explicit AI consent and a solver action, using the member's key.
- The local media library retains selected images, source/page URLs, categories, and usage counters; these are not sent to the CodeChum services.
- Confirm the Chrome Web Store data-use checkboxes and privacy URL against the final implementation and deployed privacy policy. They cannot remain at the old GoPaste-only answers.

## Review risks that copy cannot remove

Chrome's [single-purpose policy](https://developer.chrome.com/docs/webstore/program-policies/quality-guidelines) says unrelated features should be distributed separately. A combined image library and CodeChum solver may therefore be rejected even with accurate disclosure. Chrome's [Manifest V3 rules](https://developer.chrome.com/docs/webstore/program-policies/mv3-requirements) also restrict arbitrary-string or remotely sourced code execution; the generic console runner must not ship in this Store build. Never present a concealed entry, decoy listing, or a guarantee of approval.
