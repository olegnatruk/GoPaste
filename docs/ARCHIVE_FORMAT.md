# Archive Format

## Version 1 Layout

```text
metadata.json
images/<sequence>-<sha256>.<ext>
```

File names are generated by GoPaste and contain only lowercase ASCII letters, digits, hyphens, and one validated extension. Original remote file names are not used as paths.

## Metadata

```json
{
  "format": "gopaste-archive",
  "version": 1,
  "exportedAt": "2026-08-21T00:00:00.000Z",
  "items": [
    {
      "file": "images/00001-0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef.gif",
      "sha256": "hex-digest",
      "mimeType": "image/gif",
      "byteSize": 12345,
      "title": "Example",
      "tags": ["reaction"],
      "sourceUrl": "https://example.test/image.gif",
      "createdAt": "2026-08-21T00:00:00.000Z",
      "updatedAt": "2026-08-21T00:00:00.000Z"
    }
  ]
}
```

Optional fields from the data model may be included. Unknown metadata fields are ignored for forward compatibility; unknown archive versions are rejected unless a documented migration exists.

## Import Safety

- Maximum compressed archive: 250 MiB.
- Maximum declared/extracted content: 500 MiB.
- Maximum media entries: 5,000.
- Reject absolute paths, parent traversal, backslashes used as traversal, symlinks, encrypted entries, and files outside `images/` except `metadata.json`.
- Require one root `metadata.json` and unique referenced file paths.
- Validate metadata shape, MIME magic bytes, size, and SHA-256 before committing an item.
- Skip content already present by hash.
- Import valid entries in bounded batches and return counts plus per-entry failures.
- A failed entry cannot overwrite or corrupt a previously stored record.

## Export Behavior

Exports are deterministic in layout and item ordering, excluding the intentionally variable `exportedAt`. They preserve user metadata and media bytes. Archive creation reports progress and ends by downloading one `.zip` file through a user gesture-compatible path.
